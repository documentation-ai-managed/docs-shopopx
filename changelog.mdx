<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time loyalty point syncing across in-store POS and online storefronts
- Introduced customizable membership tiers with automated tier progression based on purchase history
- New email campaign builder integrated with CRM data for personalized loyalty offers

## Improvements

- Enhanced dashboard analytics with loyalty program ROI calculations
- Optimized API response times by 40% for high-volume membership queries

## Bug Fixes

- Fixed intermittent sync issues between mobile app check-ins and CRM records
- Resolved duplicate reward redemption errors in multi-location setups

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Launched unified CRM dashboard combining membership data, loyalty points, and marketing campaigns
- Added webhook support for integrating loyalty events with external e-commerce platforms like Shopify
- Introduced SMS notifications for membership milestones and reward expirations

## Breaking Changes

- Updated authentication endpoints: Replace `POST /v1/auth/login` with `POST /v2/auth/token`
- Deprecated legacy loyalty API v1; migrate to v2 for new point accrual rules

## Bug Fixes

- Corrected membership export CSV formatting for large datasets
- Fixed reward catalog caching issues causing outdated pricing displays

</Update>
